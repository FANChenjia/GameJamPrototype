# Folating Variation 浮想变奏

零依赖静态网页游戏。双击 `index.html`，或在本目录启动：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

打开 http://127.0.0.1:8767 。本地文件和不同端口的浏览器存档相互独立。

## 流程

选关 → 局外商店 → 布阵 → 战斗 / 波间布阵 → 结算。每关有效战斗 120 秒，暂停和布阵不计时。

| 岛 | 英文 | 首次开放 |
|---|---|---|
| 风鸣岛 | Windsong Island | 拨弦 |
| 星摇岛 | Starrock Island | 吹奏 |
| 鼓岩岛 | Drumrock Island | 打击 |
| 弦雾岛 | Chordmist Island | 拉弦 |
| 天空岛 | Sky Island | 全乐器综合关 |

第一岛自动布置五把里拉琴。其余关卡从乐器栏拖放，或选择乐器后点击空格。格子为横向五列、纵向四行；宽体乐器攻击其横向覆盖的每一列。

- 准备阶段、波间可以拖动单位，或选中后点击空格移动；出售仅限波间。
- 从手牌拖到乐器使用强化牌，召唤牌拖到空格，全场牌拖到战场；拖动时暂停并提示有效落点，成功落下才扣费，错误落点会弹回，Esc 取消。支持弹性跟随与落点回弹，减少动态效果偏好下取消弹性位移；点击选牌作为备用操作保留。
- 手动暂停后可以连续打出组合，再点击继续；暂停不会增长协奏点。
- 局内候选牌只在点击刷新后生成，手动刷新花费 6 协奏点；不刷新就保留当前候选；领取后仅补充该槽位，另外两张不变，可继续领取。领取和单槽补牌免费，打出才支付协奏点。局外预购支付韵律点，入场释放仍支付协奏点。
- 第三岛起每波第 1/2/3/4 次手动刷新，首槽依次保底回旋曲/华彩乐段/强音/无穷动；第五岛第 5 次再保底回旋曲。领取保底牌后该槽按普通概率补牌，补牌不推进刷新次数。候选跨波保留，下一波刷新次数从零计。推演抵扣一次手动刷新费用。
- 召唤牌从开局在局外商店开放，局内普通刷新和即兴都不产生召唤牌。
- 每波最后二十秒出现 Boss；截止时仍有在场敌人则失败。第二波起可在波间按预告的 Boss 列重新布阵。
- 失败重试恢复本关起始资源和预购牌。通关后解锁下一关并结算韵律点；重复挑战不重复领取奖励。

## 文件

- `balance.js`：15 件乐器、20 张奏法牌、概率、五岛十关二十四波数据。
- `engine.js`：0.01 秒固定步长的战斗、经济、抽选、技能、胜负及结算规则。
- `app.js`：选关、商店、卡牌交互、布阵与浏览器进度存档。
- `renderer.js` / `icons.js`：Canvas 战场与乐器图案。
- `assets/cards/`：17 张原始卡牌 PNG，古琴、唢呐、锣三张 SVG 占位卡。
- `docs/`：与当前配置同步的数值文档和完整玩法规格。

浏览器控制台可用 `concertoDebug.snapshot()` 读取战况。`concertoDebug.openLevel('3-1')` 用于本地调试指定关卡；页面不展示调试工坊或参数设置。
