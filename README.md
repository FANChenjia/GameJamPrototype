# 协奏原野 · Concerto Meadow

零依赖的静态网页游戏调试 demo。双击 `index.html` 即可使用，所有图片和图标均在本地以 Canvas / SVG 绘制，无需联网或构建。

若浏览器对本地文件有限制，可在此目录运行：

```sh
python3 -m http.server 8765
```

然后访问 `http://localhost:8765`。同一浏览器中，file 地址与 localhost 地址的存档相互独立。

## 操作

- 左侧手记分为「卡牌」和「商店」两页，点击右上角书签翻页；书签获得焦点时也可用左右方向键切换。两页共享协奏点，翻页不会重置手牌或购买记录。

- 从「你的乐团」拖入乐器，或选择乐器后点击网格；可连续放置，Esc 取消。
- 拖动场上乐器自由调整位置，同位分身一起移动。重叠或越界时保留原位。
- 每次攻击具有扩散发射光环、带尾迹的音符、命中光圈与伤害数字。
- 点击场上的乐器查看范围，Delete / Backspace 移除（同时移除其分身）。
- 点击牌堆展开三类灵感，选择卡牌后点击乐器。相同卡牌会合并展示并标注数量。
- 「急板」按基础攻速增加百分比；「延音」增加覆盖列数；「回响」在同位置生成独立攻击的分身。
- 旅人商店可使用协奏点补充卡牌。收入随演奏时间和击退怪物增长。
- 开始 / 暂停：底部主按钮或空格。2× 同步加速模拟时间、怪物和收入。
- 打开调试设置或网页进入后台时自动暂停，需点击继续恢复。
- 重置保留原始布置，清除增益与分身，恢复初始三张牌、初始点数及计时。

## 自定义

调试设置包含时长、刷怪间隔、怪物生命、行进时间、自然收入、击退奖励、初始点数、卡牌增幅和商店价格。保存后即时生效，初始点数在重置后应用。怪物生命只影响新刷怪物。

乐器工坊内置竖琴、提琴、长笛、小鼓、小号、钢琴、大提琴和风铃八种原创手绘图标。每件乐器可保存名称、攻速、伤害、攻击列数和任意连续的占格形状（最多 5×4）。偶数占格的范围必须为 2 或 4 列；延音牌也遵守该规则。

攻击从占格的几何中心发出。攻击范围以占格中心为轴：四列范围为左两列加右两列，二列范围为左一列加右一列；奇数范围包含中心列及左右相邻列。超出战场边缘的列直接截断，不平移到另一侧补齐。如果偶数范围的原点恰好位于某列正中，中轴列不计入左右列（例如原点位于第 3 列中心，四列范围覆盖第 1、2、4、5 列）。每次普攻同时命中覆盖列内的所有怪物，每只受到一次完整的单次伤害，同列多只怪物也一起受伤；不同目标的音符同时抵达。整次齐射只计一次攻速冷却，目标数量不会降低攻速。分身继承施放当时的属性，后续对原乐器施放的增益不自动同步给分身。

任何怪物抵达草地与构筑区之间的绳索即失败；坚持到设定时长即成功。页面初始显示的半透明小怪仅为来袭示意，未开始前不会移动或参与战斗。

## 存档与文件

浏览器 localStorage 保存演奏参数、乐器模板和原始布置，不保存本局实时进度。模板改动用于新放置的乐器，场上的乐器保留放置时的配置。清空浏览器站点数据可恢复首次默认配置。

- `index.html`：界面与对话框
- `style.css`：纸张、书本、响应式布局
- `icons.js`：全部原创 SVG 图案
- `engine.js`：独立于页面的战斗模拟与规则校验
- `renderer.js`：Canvas 草原、怪物、乐器与音符
- `app.js`：页面交互、工坊与存档

在浏览器控制台执行 `concertoDebug.snapshot()` 可读取当前局面快照。

