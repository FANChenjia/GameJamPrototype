# 王阵 · Crownfall

一副扑克、一枚骰子、两位君主。零第三方依赖的静态网页纸牌游戏原型，支持虎鲸 AI（才不是大肥鱼）、新手教程和局域网双人对战。

只看玩法可阅读 **[游戏规则.md](游戏规则.md)**，包含完整的简明规则与一个伤害示例。

## 开始游戏

- **人机对战：**直接双击 `index.html`。无需安装、无需联网，进度自动保存在当前浏览器。
- **局域网：**Windows 双击 `start.cmd`，或在此文件夹执行 `node server.cjs`。浏览器打开 **http://localhost:3210**。
- 点击「好友联机」→「开一张新桌」，复制邀请链接，交给连接同一 Wi-Fi / 局域网的另一位玩家。
- 对手打开邀请链接并点击「入座」。也可以先打开终端显示的局域网地址，再输入六位房间码。
- 保持开桌电脑与服务运行。双方刷新页面会自动回到各自座位；暂时断线会暂停操作并自动重连。

服务需要 **Node.js 18+**，无需 `npm install`。`start.cmd` 会优先寻找系统 Node，并兼容当前 Codex 自带的 Node 运行时。默认监听 `0.0.0.0:3210`；可用 `PORT` 环境变量更换端口。同网设备需能访问开桌电脑的此端口；访客 Wi-Fi 的设备隔离、VPN 或防火墙可能影响互通。房间保存在主机内存中，服务退出会关闭全部房间；无连接的房间两小时后回收。

## 数值与流程

| 项目 | 规则 |
| --- | --- |
| 牌堆 | 一副 54 张扑克；两张 Joker 分给两位玩家作为主将，52 张普通牌共同抽取 |
| 初始 | 只有主将，无士兵或骑士；主将 24 生命 |
| 回合 | 掷一次 D6，获得 1–6 行动点；可重复执行付费行动；结束时余点清零 |
| 抽牌 | 1 点；抽 1 张牌进入左侧备选区，容量 1 张，未用可跨回合保留 |
| 排兵 / 弃牌 | 免费；使用备选牌排成士兵，或放入弃牌堆；排兵最多 5 名，每回合最多 2 次；零行动点也可执行 |
| 士兵 | 生命等于牌面点数（1–13）；承受基础伤害的 2 倍 |
| 册封 | 2 点；选择一名士兵转入骑士层，生命恢复至「牌面点数 +4」；最多 3 名 |
| 骑士 | 生命上限为牌面点数 +4（5–17），受到正常伤害；每名存活骑士提供攻击基础伤害 +1 |
| 攻击 | 1 点；使用当前备选牌，选择最外层目标，卡牌出列展示伤害后飞向目标，命中时扣血；结算后攻击牌进入弃牌堆 |
| 攻击牌 | A–3 → 2；4–6 → 3；7–9 → 4；10/J/Q → 5；K → 6 基础伤害 |
| 层级 | 有士兵时只能选士兵；士兵清空后可攻击骑士；两层全空后可攻击主将 |
| 突破 | 击破单位消耗相应基础伤害，士兵消耗量为当前生命 ÷2 向上取整；余伤传给当前最外层生命最低的单位，同血按槽位顺序 |
| 疲劳 | 牌堆耗尽重洗弃牌，不收回在场单位；双方主将受到递增的 2、4、6… 点伤害 |
| 胜负 | 主将生命归零立即结束；同时死于疲劳则平局；联机重开需双方同意，重开交换先手 |

基础伤害公式：`1 + ceil(牌值 / 3) + 己方骑士数量`，A=1、J=11、Q=12、K=13；士兵的双倍在加上骑士增益后计算。

例如：己方有 2 名骑士，抽到 7 → 基础伤害为 4+2=6。攻击一张点数为 6 的满血士兵牌，其 6 生命消耗 3 点基础伤害；剩下 3 点继续结算，可再击破一名不超过 6 生命的士兵，或对下一名骑士 / 主将造成 3 点伤害。7 点士兵有 7 生命，册封后回满至 11；K 牌则分别为 13 / 17 生命。

1 点抽牌后可免费排兵，或再花 1 点进攻；2 点册封带来防御与进攻增益。备选容量让每次抽牌都需要决定用途，溢出机制抑制无限补兵。高点数牌更耐打，受伤的高点数士兵也有更高的册封价值。招募上限让高点数回合需要考虑进攻，疲劳推进残局。当前为原型数值，未经过真人竞技环境调优。

旧版固定生命的人机存档会自动升级，按原剩余生命比例调整到新上限（向上取整），保留牌阵、牌堆和回合。

## 交互

新手可点击页面底部「初次入座？跟着玩一局」，也可随时从左下角玩法手册中的「开始新手教程」直接进入。教程分为 14 步，使用固定骰子和牌序，配合高亮提示演练抽牌、免费排兵 / 弃牌、册封、溢出伤害及逐层突破；跟随步骤即可获胜。教学残局中虎鲸的主将已受伤至 12 生命。教程进度独立于当前对局，完成或中途退出都会返回原牌局。联机中进入教程会暂停当前房间的对弈，退出后自动重新连接原座位。

教程采用黑色聚光遮罩，仅照亮当前操作按钮或目标纸牌，保留步骤说明和退出入口；暗处拦截点击。遮罩会随选牌、掷骰、攻击、滚动和屏幕尺寸更新，键盘 Tab 可在当前操作与退出入口之间切换。通关弹窗和退出教程时自动解除遮罩。

点击桌中央的实体骰子掷骰；点「抽牌」或公共牌堆将牌放入左侧备选区，再免费排兵 / 弃牌，或花 1 点攻击；点「册封」后选择己方士兵；有备选牌时点「攻击」后选择高亮的敌方单位。选目标时可以取消或按 Esc，不消耗行动点。音效默认关闭，左侧圆形按钮开启；窄屏下工具移到页面底部。

骑士与士兵分别组成朝向主将的内弧和外弧。骰子使用连续的抛起、落桌压缩与衰减回弹，落桌前锁定最终点数。确认「重新开局」后会掀起牌桌，纸牌和骰子依各自位置、摩擦、惯性、空气阻力和重力滑散、翻飞、落下；新桌面落稳后解锁操作。结算后的再来一局，以及局域网双方同意重开，也会使用这一动画。系统开启「减少动态效果」时改为短暂淡出淡入。

快捷键：D 掷骰、F 抽牌、R 排兵、X 弃牌、C 册封、A 攻击、E 结束回合、Esc 取消选目标 / 关闭预览。所有关键操作均可通过键盘 Tab 聚焦。支持系统「减少动态效果」偏好。

视觉以 CSS / 内嵌 SVG 绘制：绒面牌桌、纸质牌面、Joker 线描、骑士徽带、立体骰子、压印按钮。攻击按「备选牌出列 → 展示伤害与骑士加成 → 蓄力突进 → 命中扣血」播放；展示期间锁定行动，AI 等动画完成后再落子，联机消息按顺序播放。刷新亮牌过程会恢复已确定的结算结果。另有发牌飞入、跨层晋升、目标呼吸、骰子弹跳、命中抖动、伤害飘字、击破散落与金色粒子，全部资源离线可用。

备选区卡牌支持悬浮 / 聚焦查看数值，手机点击固定预览。预览为打开的书本，四边内边距均为 20px，左页显示士兵生命、右页显示实时骑士加成与攻击伤害；已入阵卡牌保持原有交互。备选区、免费弃牌、存档迁移、教程和联机采用同一套规则。

## 实现与验证

- `game.js`：浏览器与服务端共用的规则引擎。
- `app.js`：静态界面、动画、AI 调度、存档与网络客户端。
- `cards.js` / `cards.css`：所有纸牌共用的矢量牌面与物理卡片样式。角标、花色、人物与骑士徽章使用固定的 100 × 140 坐标，普通牌与攻击展示牌等比缩放；生命条宽度始终限制在单张牌内。
- `table-flip.js` / `table-flip.css`：使用固定时间步长的掀桌模拟、纸牌抛体、骰子回弹，以及连续的掷骰轨迹。
- `tutorial.js`：独立的教学残局、固定牌序、骰子和操作步骤约束。
- `server.cjs`：Node 原生 HTTP 服务，REST 指令 + SSE 状态同步。房间码匹配、座位令牌验证、回合 / 费用 / 层级检查以及状态序号去重均在主机端执行。客户端收到公开牌阵与剩余牌数，不接收牌堆顺序。
- `styles.css` / `index.html`：响应式牌桌、无外部字体或 CDN。

运行 `npm test` 或 `node --test tests/*.test.cjs`：33 项测试（含备选容量、跨回合保留、零点免费操作和联机备选同步）覆盖点数、费用、招募上限、A–K 生命与晋升回血、双倍伤害、奇数生命溢出、存档迁移、AI 册封选择、死亡、递增疲劳、快照隐藏、完整联机流程、AI 强度基准、静摩擦、抛体轨迹、碰撞能量损失、骰子轨迹连续性与教程。新手教程在 1,000 组牌堆测试中均取得玩家满血胜利；实际网页也已走通完整流程、退出恢复和掀桌重置。另已在实际浏览器检查 106 种牌面（52 张普通牌、2 张 Joker、52 张骑士）在桌面、手机、攻击展示三种尺寸下的 318 个样例，未检出牌面越界、角标重叠或生命条越界。

新数值下固定随机种子的 300 局 AI 自博弈全部完成：中位数 28 回合，最长 64 回合，先手胜率 51.3%，平局 7 局。此统计用于发现死循环和显著失衡，不代表真人胜率。联机自动化测试使用本机两路独立客户端，覆盖状态一致、非法请求、断线重连、完整对局及双方重开；跨设备连接仍受实际局域网环境影响。

人机模式默认使用偏友好的「轻松 AI」，降低抢攻与册封决策的稳定性，仍遵守相同的骰子、费用、牌堆与伤害规则。以基础策略 AI 为固定对手，交替先手，用独立于调参的随机种子验证 4,000 局：轻松 AI 获胜 1,561 局、失败 2,326 局、平局 113 局，胜率 **39.02%（平局计入总局数）**。这是模拟基准，实际对人胜率取决于玩家水平。
