# Folating Variation 浮想变奏

零依赖静态网页游戏。双击 `index.html`，或在本目录启动：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

打开 http://127.0.0.1:8767 。本地文件和不同端口的浏览器存档相互独立。

## 流程

选关 → 局外商店 → 布阵 → 战斗 / 自动接波 → 结算。每关有效战斗最多 120 秒，暂停和布阵不计时。

| 岛 | 英文 | 首次开放 |
|---|---|---|
| 风鸣岛 | Windsong Island | 拨弦 |
| 星摇岛 | Starrock Island | 吹奏 |
| 鼓岩岛 | Drumrock Island | 打击 |
| 弦雾岛 | Chordmist Island | 拉弦 |
| 天空岛 | Sky Island | 全乐器综合关 |

第一关为六段可操作新手引导：放置/移动/移除 → 五列布阵 → 协奏收入与购牌 → 拖放急板 → 六点刷新 → 迎战 Boss。教学浮窗贴近当前按钮或目标格，遮罩暗化其余区域；拖动起点与落点同时露出，支持定位与键盘焦点限制。静止时按需绘制战场，浮窗和遮罩仅在状态／布局改变时更新。教学节点暂停有效时钟，随时可跳过；第一关首组免刷新费候选固定急板、强音、渐弱，均需按标价购买，后续随机池正常。

每个关卡默认空场，完整保留初始协奏点。准备阶段从乐器栏拖放，或选择乐器后点击空格。第一岛推荐手动放置五把里拉琴，每列一把。格子为横向五列、纵向四行；宽体乐器攻击其横向覆盖的每一列。

- 准备阶段可以放置、移动和移除乐器：拖动或选中后点击空格移动，点击「移除」或按 Delete / Backspace 移除并全额退还该单位实际支付的布置协奏费用；免费召唤单位返还零点；已使用的奏法牌和强化费用不返还。
- 清波后自动补发剩余时间的协奏收入并直接进入下一波，无手动确认或波间布阵；开战后移动需调弦，不能直接移除或出售。
- 卡面已禁用原生图片拖拽及文字选择。从手牌拖到乐器使用强化牌，召唤牌拖到空格，全场牌拖到战场；拖动时暂停并提示有效落点，成功落下只消耗牌，不再扣费，错误落点会弹回，Esc 取消。支持弹性跟随与落点回弹，减少动态效果偏好下取消弹性位移；点击选牌作为备用操作保留。
- 手动暂停后可以连续打出组合，再点击继续；暂停不会增长协奏点。
- 每关无系统赠送起手牌，仅携带局外预购牌；入场自动免费展示 3 张候选。之后手动整组刷新每次花费 6 协奏点；不刷新就保留当前候选；点击候选购买时按标价扣协奏点，成功后仅该槽免费展示新候选，另外两张不变；新候选仍需另买。手牌打出不再扣协奏点，零余额也能使用。局外预购只付韵律点，即兴生成入手免费；两者打出也免费。
- 第三岛起每波第 1/2/3/4 次手动刷新，首槽依次保底回旋曲/华彩乐段/强音/无穷动；第五岛第 5 次再保底回旋曲。购买保底牌后该槽按普通概率补牌，补牌不推进刷新次数。首组免刷新费候选不算手动次数；候选跨波保留，下一波刷新次数从零计。推演抵扣一次手动刷新费用。
- 召唤牌从开局在局外商店开放，局内普通刷新和即兴都不产生召唤牌。
- 普通怪持续均匀入场；常规怪移动 28 秒，突进怪为 10/12 秒，使用独立生命和暖橙色速度箭头。前两岛少用奏法会有漏怪，合适时机的强音可减少突破；每波普通击杀总收益保持原值。
- 点选建造栏或场上乐器，可查看攻击特性、被动、费用、占地、攻速、伤害；场上还显示当前增益。
- Boss 生命比上一版下调 5%，横跨三条声部，三波依次覆盖第 2–4 / 1–3 / 3–5 列；共享生命，每件乐器一次普攻只对同一 Boss 结算一次伤害，不按身体列数重复计算；马林巴七段对 Boss 合为一次 28 基础伤害，回旋曲附伤合入本次结算。不同乐器及分身仍各自攻击。Boss 在各波相对起点的最后二十秒出现，后续波随清波提前开始；截止时仍有在场敌人则失败。
- 失败重试恢复本关起始资源和预购牌，并以空场重新布阵。通关后解锁下一关并结算韵律点；重复挑战不重复领取奖励。

顶部工具栏「重置进度」可在选关、商店、战斗和教学中使用，结算与手牌整理弹窗也提供入口。确认后清空通关记录、解锁、韵律点、商店预购和当前对局，返回第一岛初始选关；取消则保留进度并恢复原先运行的战斗。

## 文件

- `balance.js`：15 件乐器、20 张奏法牌、概率、五岛十关二十四波数据。
- `engine.js`：0.01 秒固定步长的战斗、经济、抽选、技能、胜负及结算规则。
- `tutorial.js`：新手引导步骤、操作保护、暂停节点与跳过/重试。
- `app.js`：选关、商店、卡牌交互、布阵与浏览器进度存档。
- `portraits.js`：网页直接绘制的 15 种乐器、10 关 Boss 手绘卡通 SVG；`art-preview.html` 为示意图鉴。
- `renderer.js` / `icons.js`：Canvas 战场、Boss 三声部覆盖与通用图标。
- `assets/cards/`：17 张原始卡牌 PNG，古琴、唢呐、锣三张 SVG 占位卡。
- `docs/`：与当前配置同步的数值文档和完整玩法规格。

浏览器控制台可用 `concertoDebug.snapshot()` 读取战况。`concertoDebug.openLevel('3-1')` 用于本地调试指定关卡；页面不展示调试工坊或参数设置。
